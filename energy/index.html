Morocco Energy Forecasts

Day-ahead electricity demand, solar PV output and weather for Morocco's 12 regions, built with machine learning on open data and refreshed every morning by GitHub Actions. Click a region on the map to explore it. It runs entirely on free services.

    Morocco

    Reference load. ONEE publishes no open hourly or regional demand data, so the models train on a calibrated reference series: the Moroccan daily profile, holidays and Ramadan, and cooling/heating from real weather, scaled to national annual demand and split across regions by population and GDP. Treat these numbers as modelled, not metered. See the README for how to train on measured data.

    Model details
    Region boundaries: geoBoundaries (CC BY 4.0), 2015 division into 12 regions. Weather: Open-Meteo (CC BY 4.0), including the Previous Runs API for forecast verification. PV plants: MASEN Noor programme. Population: RGPH 2024 (HCP); regional GDP: HCP regional accounts. Inspired by an open energy forecasting platform for the Italian market. Source code.
