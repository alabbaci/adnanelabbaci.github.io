Morocco Energy Forecasts

Day-ahead electricity demand, solar PV output and weather for Morocco, built with machine learning on open data and refreshed every morning by GitHub Actions. It runs entirely on free services.

Reference load. ONEE publishes no open hourly demand data, so the models train on a calibrated reference series: the Moroccan daily profile, holidays and Ramadan, and cooling/heating from real weather, scaled to national annual demand. Treat these numbers as modelled, not metered. See the README for how to train on measured data.
